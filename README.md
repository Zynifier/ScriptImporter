
# Script Importer

THIS CODE IS 100% AI, NONE OF IT IS MADE BY ME.

# How to Use:

Its pretty much fully auto. Use my [FModel Fork](https://github.com/Zynifier/FModel/tree/ScriptData) and export the script of your choice (Use the editor Only Asset).
Go to File->Import FModel Niagara json and import your editor only json.
Your Script should now be imported in /Game/ImportedNiagara/YourAsset !
